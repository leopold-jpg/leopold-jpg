### 🤖 Currently shipping

> 🏗️ **Sibbjäns Ops** — Next.js + Supabase ops dashboard with an agent-ready task system. Tasks arrive with full briefs so agents can execute autonomously.
>
> 🧠 **Jarvis / OpenClaw** — Multi-agent orchestrator running in Docker on a Mac mini. Specialist sub-agents for Sibbjäns, Otiva, Tavio. WebSocket-gated, sandboxed, and (now) doesn't have root.
>
> ⚡ **Sibbjäns energy stack** — 150 kWp solar, 558 kWh battery, diesel backup, EMS-orchestrated peak shaving. Coordinating 6+ contractors across construction, electrical, KNX, and EMS.
>
> 🛠️ **AI Kollegorna** — Mac mini-based AI agents-as-a-service for Swedish SMEs. Cinematic dark aesthetic, Vercel/Linear/Stripe-coded.

### 💭 Operating principles

> *"Ship the agent. Then ship the agent that ships the agent."*

- **Bias to autonomy.** If a human has to type it twice, it's a bug.
- **Briefs over tickets.** Every task carries enough context for an agent to execute without asking.
- **Self-hosted by default.** Mac minis, Docker sandboxes, MCP servers I control.
- **European supply chain.** It's a hard requirement, not a preference.
